# mono-screenshots

Screenshots for the pull request descriptions of
[noshiro-pf/mono](https://github.com/noshiro-pf/mono), one directory per pull
request number. How they are taken and pushed is
[`docs/pr-screenshots.md`](https://github.com/noshiro-pf/mono/blob/main/docs/pr-screenshots.md)
there.

`index.html` is a viewer served by GitHub Pages. It lists one pull request's
images, pairs `before-<name>` with `after-<name>`, and moves through them with
the arrow keys:

```text
https://noshiro-pf.github.io/mono-screenshots/?pr=<number>&sha=<commit>#<file>
```
